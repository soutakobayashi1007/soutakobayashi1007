# 小林走太 / Sota Kobayashi

金融機関の現場でエンジニアをしています。仕事では分析と業務の自動化を担当して
います。個人ではトレーディング戦略の統計検証基盤をPythonで作り、Linuxサーバーで
運用しています。

## できること

得意なのは、現場の人が毎日手でやっている作業を減らすことです。

- データの集計・突合・分析・レポート化（Python / pandas / SAS）
- 業務の自動化とツール化（Python / PowerShell / VBA / Google Apps Script）
- 分析や検証が「本当に正しいか」を確かめる仕組みの設計
- 要件のヒアリングから、実装・納品・引き継ぎまでの一連

守秘の扱い: 業務で作ったコードと業務仕様は公開しません。個人の研究も、
戦略の中身とデータは非公開にしています。

## 経歴

- 金融機関に常駐するエンジニア。規制対応部門を経て、いまは保証領域で分析と
  業務自動化をしています（SAS / PowerShell / VBA / Python）。初案件から
  ビジネスサイドを兼務しており、要件の汲み取りと組み立てが得意です
- その前は個人事業主として、小売・EC事業者の業務自動化を受託していました。
  要件のヒアリングから実装、納品、引き継ぎまで単独で担当
- 個人プロジェクトとして、仮説の事前登録・順列検定・多重比較補正を組み込んだ
  検証基盤をPythonで作り、Linuxサーバーで運用しています。
  91本の仮説を検定して、事前に決めた判定を通ったのが5本、
  実際に資金を入れてよいという別の基準まで通ったのは0本、
  実装して動かしているのは1本です
- スペインの大学で機械工学を3年次まで（Universitat Politècnica de València）。
  18歳で渡西し、4年弱スペイン語で生活していました
